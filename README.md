# SpendWise — سبيندوايز 💰

تطبيق ذكي لتحليل وتصنيف مصروفاتك الشخصية الشهرية، وتتبع أنماط الإنفاق، وتقديم رؤى تساعدك على تحسين إدارة ميزانيتك — **يعمل بالكامل على جهازك، دون رفع بياناتك المالية لأي خادم خارجي.**

> هذا هو **الإصدار الأول (Phase 1)** من SpendWise، مبني بتصميم قابل للتوسع لدعم مراحل مستقبلية دون الحاجة لإعادة بناء الأساس.

---

## 🔒 الخصوصية أولًا

- جميع بياناتك (المعاملات، التصنيفات، الميزانية) تُحفظ محليًا فقط داخل قاعدة بيانات SQLite على جهازك.
- الملفات التي ترفعها (Excel/PDF) تُستخدم فقط لاستخراج البيانات، ثم **تُحذف فورًا** — لا يُحفظ الملف الأصلي أبدًا.
- لا يتم حفظ أرقام الحسابات، الآيبان، أرقام الهوية، أو أي معلومات تعريفية شخصية — فقط اسم تاجر مُنقّى من هذه المعلومات.
- ميزة التصنيف الذكي (AI) **اختيارية بالكامل** ومعطّلة افتراضيًا، ولا تُرسل إلا اسم التاجر المُنقّى + المبلغ فقط.
- راجع [docs/privacy.md](docs/privacy.md) لتفاصيل كاملة.

## 🚀 التثبيت والتشغيل (خطوة بخطوة)

### على ويندوز (Windows)

1. افتح مجلد المشروع (الذي يحتوي هذا الملف).
2. انقر نقرًا مزدوجًا على الملف `scripts\setup_windows.bat` (أو شغّله من موجّه الأوامر Command Prompt). سيقوم بإنشاء بيئة بايثون، تثبيت المتطلبات، وإعداد قاعدة البيانات تلقائيًا.
3. بعد اكتمال الإعداد، شغّل `scripts\run_windows.bat` في كل مرة تريد فتح التطبيق.
4. سيفتح المتصفح تلقائيًا على عنوان مثل `http://localhost:8501`.

### على macOS أو Linux

```bash
bash scripts/setup_unix.sh   # مرة واحدة فقط
bash scripts/run_unix.sh     # في كل مرة تريد تشغيل التطبيق
```

## ☁️ الاستضافة على الإنترنت (اختياري — لمن لا يستطيع التثبيت محليًا)

الطريقة الأساسية لاستخدام SpendWise هي تشغيله محليًا على جهازك (كما بالأعلى) — بهذا الشكل تبقى بياناتك على جهازك بالكامل. لكن إذا كان جهازك مُدار من جهة عملك وتمنع تثبيت برامج بايثون (سياسات أمنية)، يمكنك بدلًا من ذلك استضافة SpendWise مجانًا على الإنترنت، على رابط خاص بك محمي بكلمة مرور.

**تنبيه مهم بخصوص الخصوصية:** في هذا السيناريو، بياناتك (المصنّفة والمُنقّاة كما هو معتاد) ستُحفظ على خادم قاعدة بيانات سحابي مجاني (وليس على جهازك فقط)، وتبقى خاصة بك ولا يراها أحد آخر إلا من يملك رابط تطبيقك وكلمة المرور. إن كنت تفضّل عدم القيام بذلك، ناقش مع قسم تقنية المعلومات في جهة عملك إمكانية السماح بتشغيل بايثون محليًا بدلًا من ذلك.

### الخطوة ١: أنشئ قاعدة بيانات سحابية مجانية (Neon)

1. اذهب إلى [neon.tech](https://neon.tech) وأنشئ حسابًا مجانيًا (يمكنك التسجيل عبر GitHub مباشرة).
2. أنشئ مشروعًا جديدًا (New Project) — اختر أي اسم.
3. من لوحة المشروع، انسخ **رابط الاتصال (Connection String)** — يبدأ بـ `postgresql://...`. احتفظ به، ستحتاجه في الخطوة ٣.

### الخطوة ٢: ارفع المشروع إلى GitHub

اتبع تعليمات "رفع المشروع إلى GitHub" أدناه إن لم تكن قد فعلت ذلك بعد. يجب أن يكون المستودع (Repository) إما عامًا (Public) أو خاصًا (Private) — كلاهما يعمل مع Streamlit Community Cloud.

### الخطوة ٣: انشر التطبيق على Streamlit Community Cloud

1. اذهب إلى [share.streamlit.io](https://share.streamlit.io) وسجّل الدخول بحساب GitHub نفسه.
2. اضغط "New app"، واختر مستودع SpendWise الذي رفعته، والفرع `main`، وحدد ملف التطبيق: `app.py`.
3. قبل الضغط على "Deploy"، افتح قسم "Advanced settings" → "Secrets"، وألصق فيه النص التالي (عدّل القيم بين علامتي الاقتباس بمعلوماتك الفعلية):

```toml
DATABASE_URL = "الرابط_الذي_نسخته_من_Neon"
SPENDWISE_APP_PASSWORD = "اختر_كلمة_مرور_قوية_من_عندك"
GEMINI_API_KEY = "اختياري - مفتاح Gemini إن أردت تفعيل الذكاء الاصطناعي"
```

4. اضغط "Deploy". بعد دقيقة أو دقيقتين سيكون تطبيقك جاهزًا على رابط مثل `https://اسم-تطبيقك.streamlit.app`.
5. افتح الرابط، أدخل كلمة المرور التي اخترتها، واستخدم التطبيق تمامًا كما لو كان محليًا — بياناتك الآن محفوظة بأمان في قاعدة بيانات Neon بدلًا من ملف SQLite المحلي.

### ملاحظات

- يمكنك الوصول لهذا الرابط من أي جهاز متصل بالإنترنت (بما فيها متصفح جهاز العمل)، دون الحاجة لتثبيت أي شيء عليه.
- أي تحديث تدفعه لاحقًا إلى GitHub (`git push`) يُطبَّق تلقائيًا على النسخة المنشورة خلال دقائق.
- لتغيير كلمة المرور أو رابط قاعدة البيانات لاحقًا: من لوحة تحكم Streamlit Cloud، افتح تطبيقك → Settings → Secrets، وعدّل القيم ثم أعد التشغيل (Reboot).

## 🤖 تفعيل التصنيف الذكي (اختياري)

الإصدار الافتراضي يعمل بالكامل محليًا عبر قواعد تصنيف ذكية بدون إنترنت. إذا أردت تفعيل المساعدة الإضافية من الذكاء الاصطناعي (Gemini، مجانًا):

1. احصل على مفتاح API مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey).
2. افتح ملف `.env` في مجلد المشروع (تم إنشاؤه تلقائيًا عند الإعداد) بأي محرر نصوص.
3. ضع المفتاح في السطر: `GEMINI_API_KEY=ضع_مفتاحك_هنا`
4. شغّل التطبيق، واذهب إلى صفحة "⚙️ الإعدادات"، ثم فعّل "التصنيف الذكي عبر الإنترنت" بعد الموافقة على شروط الخصوصية.

يمكنك تعطيل هذه الميزة في أي وقت من نفس الصفحة، وسيستمر التطبيق بالعمل بشكل طبيعي بالاعتماد على القواعد المحلية فقط.

راجع [docs/ai_providers.md](docs/ai_providers.md) لتفاصيل أكثر، وكيفية استبدال Gemini بمزوّد آخر مستقبلًا (مثل تشغيل نموذج محلي عبر Ollama).

## 💾 النسخ الاحتياطي والاستعادة

من صفحة "📊 التقارير والنسخ الاحتياطي":
- **نسخة احتياطية كاملة**: تُصدّر قاعدة بياناتك وإعداداتك كملف `.zip` واحد يمكنك حفظه في مكان آمن.
- **الاستعادة**: يمكنك استعادة نسخة احتياطية سابقة — يأخذ التطبيق نسخة أمان تلقائية من بياناتك الحالية قبل أي استبدال.
- **حزمة بيانات محمولة**: لنقل بياناتك المصنّفة (بدون ملفات حساسة) بين الأجهزة أو استعادتها بعد إعادة تثبيت.

## 🐙 رفع المشروع إلى GitHub (خطوة بخطوة)

بعد إتمام الإعداد بنجاح على جهازك، افتح Terminal (أو Git Bash على ويندوز) داخل مجلد المشروع ونفّذ الأوامر التالية بالترتيب:

```bash
git init
git add .
git commit -m "النسخة الأولى من SpendWise"
```

ثم أنشئ مستودعًا (Repository) جديدًا فارغًا في حسابك على GitHub (بدون إضافة README أو .gitignore عند الإنشاء)، وانسخ رابط المستودع، ثم:

```bash
git remote add origin <رابط-المستودع-من-GitHub>
git branch -M main
git push -u origin main
```

**ملاحظة مهمة:** ملف `.gitignore` المرفق يمنع رفع بياناتك الفعلية (قاعدة البيانات، ملف `.env` بمفاتيحك السرية، الملفات المرفوعة) — لن تُرفع أي بيانات حساسة إلى GitHub.

│   ├── mapping/                 # تطابق الأعمدة والتطبيع

├── docs/                         # التوثيق التفصيلي
