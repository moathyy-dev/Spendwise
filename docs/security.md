# ملاحظات أمنية

## معالجة الملفات المرفوعة

- امتدادات مدعومة فقط: `.xlsx`, `.xls`, `.pdf`. أي امتداد آخر يُرفض.
- امتدادات تحتوي وحدات ماكرو (`.xlsm`, `.xlsb`) تُرفض صراحةً — لا تنفيذ لأي محتوى مضمّن أبدًا.
- حجم أقصى للملف (25 ميجابايت افتراضيًا) لمنع رفع ملفات ضخمة عن طريق الخطأ أو الإساءة.
- أسماء الملفات المؤقتة تُولَّد عشوائيًا (UUID) — لا يُستخدم اسم الملف الأصلي أبدًا كمسار على القرص، لمنع هجمات اجتياز المسار (Path Traversal).
- الملفات المؤقتة تُحذف دائمًا (`try/finally`) حتى عند حدوث خطأ أو إلغاء.

## حماية التصدير

- تصدير Excel يحمي من حقن الصيغ (Formula Injection): أي قيمة نصية تبدأ بـ `=`, `+`, `-`, `@` تُسبق بفاصلة عليا (`'`) لتُعامل كنص وليس كصيغة قابلة للتنفيذ في Excel/LibreOffice.

## الأسرار (Secrets)

- مفاتيح API (مثل `GEMINI_API_KEY`) تُقرأ فقط من ملف `.env` المحلي، ولا تُحفظ أبدًا في قاعدة البيانات أو تُعرض في الواجهة أو تُسجَّل في أي سجل (Log).
- ملف `.gitignore` يستثني `.env` وأي ملف `*.key` من التتبع في Git.
- `.env.example` يحتوي على أسماء المتغيرات فقط، بدون أي قيم حقيقية.

## النسخ الاحتياطي والاستعادة

- الاستعادة تتحقق من إصدار تنسيق ملف النسخة الاحتياطية قبل المتابعة، وترفض أي ملف غير متوافق.
- قبل أي استعادة، تؤخذ نسخة أمان تلقائية من قاعدة البيانات الحالية (`*.pre_restore_backup.db`) لمنع فقدان البيانات عن طريق الخطأ.

## الاعتماديات (Dependencies)

- جميع الاعتماديات مثبّتة بإصدارات محدّدة (Pinned) في `requirements.txt` لضمان استقرار وقابلية إعادة البناء.
- يُنصح بتحديث الاعتماديات دوريًا ومراجعة أي تنبيهات أمنية معروفة (عبر `pip list --outdated` أو أدوات مماثلة).

## عدم وجود تتبع خارجي

- لا يحتوي SpendWise على أي تحليلات استخدام (Telemetry) أو اتصالات خارجية بخلاف ما تُفعّله صراحةً (الذكاء الاصطناعي الاختياري، أسعار الصرف الاختيارية عبر الإنترنت).
