# مزوّدو الذكاء الاصطناعي

## لماذا Gemini افتراضيًا؟

تم اختيار Gemini (الفئة المجانية) كمزوّد افتراضي بعد مقارنة عدة خيارات بناءً على: فهم اللغة العربية، دعم إخراج JSON منظّم وموثوق، الخصوصية (لا يُرسل إلا حقول مُنقّاة)، الموثوقية، التكلفة (مجاني ضمن حدود سخية)، زمن الاستجابة، وسهولة التكامل عبر SDK رسمي لبايثون.

## كيف يعمل التكامل

- كل التفاعل يمر عبر واجهة مجردة `AIProvider` (`src/spendwise/ai_provider/base.py`) — التطبيق لا يعرف تفاصيل أي مزوّد محدد.
- `GeminiProvider` هو التنفيذ الفعلي: يبني دفعات من حتى 25 معاملة، يطلب إخراج JSON منظّم بدرجة حرارة 0 (لأقصى ثبات)، مع إعادة محاولة (Retry) بتأخير تصاعدي عند الفشل المؤقت.
- أي استجابة غير صالحة (JSON تالف، تصنيف غير معروف، ثقة خارج النطاق) تُفلتر بأمان دون كسر عملية الاستيراد بأكملها.
- عند تعطيل الذكاء الاصطناعي أو عدم توفر مفتاح API، يُستخدم `NullAIProvider` تلقائيًا — التطبيق يستمر بالعمل بالقواعد المحلية فقط.

## البيانات المُرسلة

فقط: اسم التاجر المُنقّى (بدون أي معلومة حساسة)، المبلغ، الاتجاه (مدين/دائن)، وقائمة أسماء التصنيفات المتاحة. لا يُرسل الوصف الأصلي أو أي معرّف شخصي أبدًا — راجع [privacy.md](privacy.md).

## التبديل إلى مزوّد آخر مستقبلًا (مثل Ollama محلي)

نظرًا لتصميم الواجهة المجردة، إضافة مزوّد جديد لا يتطلب تعديل أي كود موجود:

1. أنشئ ملفًا جديدًا مثل `src/spendwise/ai_provider/ollama_provider.py`.
2. اجعله ينفّذ `AIProvider`:

```python
from spendwise.ai_provider.base import AIProvider, AIClassificationOutput, AITransactionInput

class OllamaProvider(AIProvider):
    def is_configured(self) -> bool:
        ...  # تحقق من توفر الخادم المحلي

    def classify_batch(self, transactions, categories):
        ...  # نفّذ الاستدعاء الفعلي وأرجع قائمة AIClassificationOutput
```

3. سجّله في `src/spendwise/ai_provider/__init__.py::build_ai_provider` عند `settings.ai_provider == "ollama"`.
4. أضف `SPENDWISE_AI_PROVIDER=ollama` في ملف `.env`.

لا حاجة لتعديل `categorize/service.py` أو أي طبقة أخرى — كلها تتعامل فقط مع الواجهة المجردة `AIProvider`.

## حدود الثقة

- **نسبة الاعتماد التلقائي المحلي** (افتراضيًا 95%): تصنيف القواعد المحلية بهذه الثقة أو أعلى يُعتمد دون الحاجة لمراجعة إضافية.
- **نسبة اللجوء للذكاء الاصطناعي** (افتراضيًا 80%): أي معاملة بثقة محلية أقل من هذه النسبة (أو غير مصنّفة) تُرسل للذكاء الاصطناعي إن كان مفعّلًا.
- كلا الحدين قابل للتعديل من صفحة الإعدادات.
