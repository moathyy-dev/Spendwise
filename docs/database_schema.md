# هيكل قاعدة البيانات

قاعدة البيانات SQLite محلية، تُدار عبر SQLAlchemy وتُرحّل عبر Alembic (`migrations/`). جميع القيم المالية من نوع `Numeric` (تُقرأ كـ `Decimal` في بايثون) — لا فاصلة عائمة ثنائية أبدًا. حقول التاريخ من نوع `Date` (وليس `DateTime`) لضمان صحة مقارنات التاريخ التامة وحدود الأشهر تحت SQLite.

## الجداول الرئيسية

### `family_members`
عضو عائلة (أو "أنا" في الاستخدام الفردي). كل بيانات أخرى مرتبطة بعضو عبر `family_member_id`، ما يضمن عزلًا تامًا بين الأعضاء.

### `accounts`
حساب مصرفي/بطاقة، يخص عضوًا واحدًا (`alias` فريد لكل عضو — لا يُخمَّن تلقائيًا أبدًا، يختاره المستخدم يدويًا).

### `categories`
تصنيفات هرمية (رئيسي/فرعي عبر `parent_id` ذاتي الإشارة)، عربية بالكامل، قابلة للتعديل والتعطيل.

### `rules`
قواعد التصنيف المحلية: `rule_type` (مطابقة تامة/اسم تاجر/كلمة مفتاحية/متعلّمة)، `pattern`، `category_id`، `priority` (الأصغر يُجرَّب أولًا)، ويمكن أن تكون عامة (`family_member_id = NULL`) أو خاصة بعضو.

### `file_fingerprints`
بصمة أحادية الاتجاه لكل ملف مستورد، مرتبطة بحساب معيّن، لمنع الاستيراد المكرر لنفس الملف.

### `import_batches`
كل عملية استيراد معتمدة تُسجَّل كدفعة واحدة (`DRAFT` → `COMMITTED` أو `ROLLED_BACK`)، تسمح بالتراجع الآمن عن آخر استيراد.

### `fx_rates`
سجل أسعار الصرف المستخدمة فعليًا (يدوي أو عبر الإنترنت)، مع التاريخ والمصدر.

### `transactions`
المعاملة المالية بعد التنقية والتصنيف والاعتماد:
- `txn_date` (Date)، `amount` (المبلغ الأصلي بعملته)، `direction` (مدين/دائن)
- `original_currency`، `base_amount` (بالعملة الأساسية بعد التحويل)، `fx_rate_id`
- `txn_type` (مصروف/دخل/تحويل/استرداد/رسوم/سحب نقدي)
- `category_id`، `merchant_sanitized` (الاسم المُنقّى فقط — لا وصف أصلي أبدًا)
- `classification_source` + `confidence` + `matched_rule_id`: شفافية كاملة حول كيفية التصنيف
- `review_status`: معتمد تلقائيًا/بانتظار المراجعة/معتمد/مستبعد
- `is_transfer`, `linked_transaction_id`: لربط طرفي التحويل أو الاسترداد بالمعاملة الأصلية
- `is_probable_duplicate`, `duplicate_of_id`: لتتبع الاشتباه بالتكرار دون حذف تلقائي أبدًا
- `row_fingerprint`: بصمة الصف (لأغراض كشف التكرار داخل الحزمة وعبرها)

### `budgets`
ميزانية إجمالية واحدة لكل (عضو، شهر) في هذا الإصدار — راجع `docs/roadmap.md` لنقطة التوسع لميزانيات على مستوى التصنيف.

## الترحيلات (Migrations)

جميع تغييرات الهيكل تمر عبر Alembic:

```bash
alembic revision --autogenerate -m "وصف التغيير"
alembic upgrade head
```

يُستخدم `render_as_batch=True` لدعم تعديلات `ALTER TABLE` تحت SQLite.
