# خارطة الطريق ونقاط التوسع

هذا الإصدار (Phase 1) يغطي دورة كاملة: استيراد → مراجعة واعتماد → تخزين → لوحة معلومات → مقارنات → تصدير → نسخ احتياطي/استعادة، لعضو واحد أو عدة أفراد عائلة بعزل تام بين بياناتهم.

فيما يلي نقاط التوسع الموثّقة في التصميم الحالي — **بدون التزام بتنفيذها في مرحلة محددة**، فقط توثيق أن الأساس يدعمها دون الحاجة لإعادة بناء الطبقات الأساسية:

## ميزانيات على مستوى التصنيف
حاليًا: ميزانية إجمالية واحدة لكل (عضو، شهر). يمكن مستقبلًا إضافة عمود `category_id` اختياري لجدول `budgets` لدعم ميزانيات فرعية، مع الحفاظ على التوافق مع البيانات الحالية.

## مزوّدو ذكاء اصطناعي إضافيون
الواجهة المجردة `AIProvider` جاهزة لإضافة أي مزوّد جديد (نموذج محلي عبر Ollama، مزوّد آخر عبر API) دون تعديل بقية التطبيق — راجع [ai_providers.md](ai_providers.md).

## مزوّدو أسعار صرف إضافيون
نفس النمط عبر واجهة `FxProvider` المجردة.

## قواعد تصنيف متقدمة
نموذج `Rule` يدعم بالفعل أنواعًا متعددة وأولوية رقمية صريحة، ما يسمح بإضافة أنواع مطابقة جديدة (مثل التعبيرات النمطية) دون تغيير هيكل قاعدة البيانات.

## تعدد العملات المتقدم
جدول `fx_rates` يحتفظ بتاريخ ومصدر كل سعر صرف مستخدم فعليًا، ما يسمح مستقبلًا بعرض سجل تاريخي لأسعار الصرف المستخدمة أو تحليل أثر تقلبات العملة.

## تقارير وتحليلات إضافية
طبقة `analytics/` مفصولة تمامًا عن طبقة التخزين، ما يسهّل إضافة مقاييس جديدة (مثل تحليل الاتجاهات طويلة المدى، أو تصنيف المصروفات الثابتة/المتغيرة بشكل أدق) دون التأثير على الاستيراد أو التصنيف.

## تطبيقات إضافية (جوال/سطح مكتب)
طبقة المنطق (`src/spendwise/`) مفصولة تمامًا عن طبقة الواجهة (`ui/`)، ما يسمح مستقبلًا ببناء واجهة أخرى (تطبيق سطح مكتب أو جوال) تعيد استخدام نفس الطبقات الأساسية دون تكرار المنطق.
